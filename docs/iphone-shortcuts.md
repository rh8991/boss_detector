# עדכון אוטומטי מהאייפון (כניסה/יציאה מהמשרד)

האייפון של הבוס שולח בקשה קטנה לשרת כשהוא מגיע למשרד וכשהוא יוצא ממנו:

- **הגעה** → הסטטוס מתעדכן ל"במשרד · פנוי"
- **יציאה** → הסטטוס מתעדכן ל"לא במשרד"

בדף הצופים יופיע "(אוטומטי)" ליד שעת העדכון.

> **הסכמה:** מדובר במעקב מיקום. מגדירים את זה רק על הטלפון של הבוס, על ידה או בהסכמתה המפורשת,
> והיא יכולה לכבות את זה בכל רגע (ראו "איך מכבים" למטה). האייפון מקבל רק את `HOOK_TOKEN`,
> שמאפשר לשלוח הגעה/יציאה בלבד.

## מה צריך לפני שמתחילים

1. **כתובת ה-Worker**, למשל `https://boss-status.<subdomain>.workers.dev`.
   חשוב: זו כתובת ה-Worker, **לא** כתובת ה-GitHub Pages.
2. **`HOOK_TOKEN`**: הקוד ששמרת בסוד `HOOK_TOKEN` ב-GitHub.

הכתובת המלאה שהאייפון ישלח אליה:

```
https://boss-status.<subdomain>.workers.dev/api/hook?token=<HOOK_TOKEN>
```

## הגדרה באפליקציית "קיצורים" (Shortcuts)

צריך ליצור **שתי** אוטומציות: אחת להגעה ואחת ליציאה.

### אוטומציה 1: הגעה למשרד

1. פותחים את **קיצורים** ← לשונית **אוטומציה** ← **+** (אוטומציה חדשה).
2. בוחרים **הגעה** (Arrive).
   - **מיקום** ← מחפשים את כתובת המשרד ← מכוונים רדיוס של בערך 100–150 מטר.
   - זמן: **בכל עת**.
   - בוחרים **הפעל מיד** (Run Immediately), ולא "הפעל לאחר אישור".
   - אם לא רוצים התראה בכל פעם, מכבים את **הודע בעת הפעלה** (Notify When Run).
   - **הבא**.
3. **אוטומציה ריקה חדשה** ← **הוסף פעולה** ← מחפשים **קבלת תוכן כתובת URL** (Get Contents of URL).
   - בשדה הכתובת מדביקים את הכתובת המלאה מלמעלה.
   - לוחצים על החץ **›** כדי לפתוח את האפשרויות:
     - **שיטה (Method):** `POST`
     - **כותרות (Headers):** מוסיפים `Content-Type` עם הערך `application/json`
     - **גוף הבקשה (Request Body):** `JSON` ← מוסיפים שדה: מפתח `event`, סוג **טקסט**, ערך `enter`
4. **סיום**.

### אוטומציה 2: יציאה מהמשרד

חוזרים על אותם שלבים, עם שני הבדלים:

- בשלב 2 בוחרים **יציאה** (Leave) במקום **הגעה**.
- בשלב 3 הערך של `event` הוא `exit` במקום `enter`.

## בדיקה

- מריצים את האוטומציה ידנית מתוך אפליקציית קיצורים (לוחצים עליה ואז על ▶︎) ובודקים שדף הצופים התעדכן
  ושמופיע "(אוטומטי)".
- אם מופיעה תשובה `{"ignored": true, ...}`, זה תקין. זה אחד מכללי ההגנה שלמטה.

## כללי הגנה מובנים

- **אותו אירוע פעמיים תוך 5 דקות לא נספר.** כך נמנע ריצוד של ה-GPS ליד הדלת.
- **עדכון ידני גובר.** אם הבוס עדכנה את הסטטוס בעצמה ב-15 הדקות האחרונות, האייפון לא דורס אותו.

## טיפים

- צריך שהמיקום יהיה פעיל עבור קיצורים: **הגדרות ← פרטיות ואבטחה ← שירותי מיקום ← קיצורים**.
  כדאי להפעיל גם **מיקום מדויק**.
- iOS מפעיל לפעמים הגעה/יציאה באיחור של כמה דקות. זו התנהגות של האייפון, לא של השרת.
- במשרדים בבניינים גבוהים או צפופים כדאי רדיוס גדול יותר (200 מטר) כדי למנוע הפעלות כפולות.

## איך מכבים

- באפליקציית קיצורים ← אוטומציה ← מכבים או מוחקים את שתי האוטומציות, **או**
- מחליפים את הקוד: `npx wrangler secret put HOOK_TOKEN` עם ערך חדש. כל האוטומציות הקיימות יפסיקו
  לעבוד עד שיעודכנו לקוד החדש.
